# sub2api frontend

This repository contains the Vue/Vite frontend from the local sub2api project. It does not contain the backend, database, account data, or deployment secrets.

## Development

Install dependencies with `pnpm install`, then run `pnpm dev`. The development server expects a compatible sub2api backend for API requests.

Run `pnpm test:run`, `pnpm lint:check`, and `pnpm build` before publishing a release.
