# JLAi 前端 UI 重构说明

基于 sub2api v0.2.17（commit `b0a02a3`），只改动 `frontend/`，不动后端与核心业务逻辑。

## 怎么跑

```bash
cd frontend
pnpm install --frozen-lockfile   # 没有新增 npm 依赖，lockfile 不变
pnpm dev                         # 开发
pnpm build                       # 生产构建
pnpm lint && pnpm test:run        # 自检（本次改动在离线环境完成，请在本地跑一遍；build 自带 vue-tsc）
```

three.js 没有走 npm，而是以 tree-shaken 的 ESM 包随代码一起提交（`src/lib/three/three-solar.js`，MIT），
附带手写的类型声明 `three-solar.d.ts`。想换回 npm 版本见 `src/lib/three/README.md`。

## 上线前要做的一件事

后台 → 系统设置 → 站点名称 改成 `JLAi`。
前端所有默认文案已经是 JLAi，但站点名称来自后端设置项，后端默认值仍是 `Sub2API`。
如果希望后端默认值也改掉，仓库根目录附了一个可选补丁 `optional-backend-brand-rename.patch`（只改字符串字面量，含测试），
`git apply optional-backend-brand-rename.patch` 即可，不应用也不影响前端。

## 改了什么

### 设计系统（`src/style.css`、`tailwind.config.js`、`tailwind.palette.js`）
- 暖色系：纸色底 `#F7F5F2`、墨色文字 `#1C1714`、珊瑚主色 `#E85A2C`、金色点缀；暗色模式是暖的乌木黑而不是冷蓝灰。
- 状态色（红/绿/黄/蓝…）经 OKLCH 统一降饱和，和暖色底不打架。
- 字体：S2A Sans / S2A Mono（Mona Sans 子集重命名，OFL 许可，见 `src/assets/fonts/OFL.txt`），标题用宽体字重。
- 统一的控件圆角、阴影、焦点环、过渡曲线；按钮 / 输入框 / 卡片 / 表格 / 徽章 / 弹窗 / Toast / 侧边栏等组件类全部重写。

### 首页（`src/views/HomeView.vue`、`src/components/home/`）
- 滚动叙事：太阳系作为固定的「舞台」占满首屏，向下滚动时下面的内容滑上来盖住它（舞台随之缩小变暗并停止渲染），
  每一层内容进入视口时依次浮现；右侧有分节导航点，首屏底部有滚动提示。
- 层次依次为：一句话说明 + CTA + API 地址 + 支持的模型 → 「一道网关」路由示意图 → 「换三行，接入完成」：
  代码面板在进入视口时逐字「敲出」真实可运行的接入示例（Python / Node.js / Java / Go / cURL，官方 SDK 写法，
  base URL 自动填成本站配置；`HomeCodeTyper.vue`）→ 「图像与视频生成」（两个工作区的真实界面截图，装在窗口框里，
  中英文各一套；`HomeStudios.vue`）→ 三个特性 → 「技术支持」（文档、后台配置的联系方式、控制台）→ 收尾。
- 首页工作区截图放在 `public/showcase/`，文件名固定：`image-studio.en.jpg`、`image-studio.zh.jpg`、
  `video-studio.en.jpg`、`video-studio.zh.jpg`（1600 × 1268，可用任意同比例截图覆盖，不用改代码）。
- 首页与工作区的文案（`src/i18n/locales/{en,zh}/landing.ts`、`studio.ts`）已按产品说明的口吻重写，去掉了修辞性的句子。
- 纯黑宇宙背景，三维太阳系 `SolarSystem.vue`（three.js + 自定义 shader）：
  真实贴图的八大行星与卫星、昼夜分界与夜景灯光、地球云层与云影、土星环双向投影、
  天王星侧躺、太阳表面流动 + 日冕 + 日珥 + 镜头光晕 + 泛光、小行星带（实例化岩石）、柯伊伯带、
  彗星（离子尾 + 尘埃尾，靠近太阳时才点亮）、银河天幕与闪烁星点。
- 开场是设计好的构图：相机从太阳表面拉开，停在固定机位时彗星正掠过太阳、地球与月亮在日旁、
  木星居右、土星带环在前景、天王星与海王星远处——之后行星按各自周期继续公转。
- 交互：拖拽环绕；Ctrl/⌘ + 滚轮或双指缩放（普通滚动不会被劫持）；点击行星跟随，点击空处回到全景；
  5 秒无操作自动缓慢环绕；页面不可见或滚出视口时停止渲染；`prefers-reduced-motion` 时静止；
  无 WebGL 时退化为 CSS 星空。
- 页面说明网站用途：标题 / 副标题 / 描述 / CTA / API 地址复制 / 支持的模型 → 「一道网关」的实时路由示意图
  （`HomeSwitchyard.vue`）→ 三个特性说明 → 收尾 CTA → 页脚（含贴图署名，CC BY 要求）。
- 手机 / 平板：文案在上，太阳在下，相机自动拉远以容纳外行星。
- 自定义首页 HTML / 紧凑模式（compact mode）逻辑不变。

### 品牌
- 新 logo `public/logo.svg`：粗体 J + 等离子轨道 + 作为 i 点的电子。
- 全部 `Sub2API` 文案改为 `JLAi`（含 i18n、测试、`index.html` 标题）。

### 登录改成弹框（`src/components/layout/AuthLayout.vue`）
- 登录 / 注册 / 找回密码等页面统一渲染成悬浮在夜空上的对话框，右上角 × 或 Esc 回首页。
- 首页点「登录」、任何需要登录的页面被守卫跳转，看到的都是这个弹框；登录后仍按原逻辑跳回目标页。路由与鉴权逻辑未改。

### 密钥页「复制」菜单（`src/utils/keyQuickCopy.ts`）
- 每个密钥多一个「复制」按钮，按密钥所在分组的平台给出可直接粘贴的配置：
  Claude Code（`ANTHROPIC_BASE_URL` 用站点根地址）、Codex CLI（`config.toml` 指向 `<根地址>/v1`，另有环境变量项）、
  Gemini CLI（`GOOGLE_GEMINI_BASE_URL`）、仅密钥；Antigravity 分组走 `/antigravity` 子路径，OpenAI 分组按
  `allow_messages_dispatch` 决定是否给 Claude Code 项。端点规则与「使用密钥」弹窗一致，弹窗保留作完整指南。

### 生图 / 生视频工作区（`src/views/user/studio/`、`src/api/studio.ts`）
- 侧边栏「创作」分组下新增两页：`/studio/image`、`/studio/video`，所有登录用户可见。
- 工作区用用户自己选的 API 密钥直接调用网关的公开接口（`/v1/images/generations`、`/v1/videos/generations` 与状态 / 内容接口），
  和外部客户端走同一条路，**计费、限额、用量记录完全沿用网关现有逻辑**，不需要新增后端代码。
- 模型来自「可用渠道」接口中计费模式为 image / video 的模型（带单价），没有配置价格时给平台默认模型，也可手动输入。
  平台规则与网关一致：生图支持 OpenAI、Grok 分组；生视频支持 Grok、聚合分组。
- 实时反馈：OpenAI 生图开流式 `partial_images`，半成品逐帧显影；视频轮询状态，队列带「已提交 → 排队 → 渲染 → 完成」，
  成片经网关取回后直接播放；遥测行、进度环、耗时、可取消、本会话胶片条、下载 / 复用提示词。
- 版式不是「左表单右结果」的聊天 / Playground 套路，而是取景器 / 剪辑台：顶部一条 HUD（密钥 · 模型 · 费用 · 状态，
  点密钥或模型展开选择面板），中央是取景器 / 监视器（空闲时显示取景框与三分线 / 胶片齿孔），左侧竖向胶片条放本次结果，
  底部一条指令条（一行式提示词、画幅 / 质量 / 张数或画幅 / 分辨率 / 时长刻度尺、参考图素材槽、圆形快门键，
  快门外圈即进度环，⌘/Ctrl + ↵ 触发）。手机端自动堆叠成单列。
- 内置提示词技能库（`src/data/studioSkills.ts`、`src/components/studio/StudioSkills.vue`）：指令条左侧的 ✦ 按钮弹出，
  生图 25 个技能（摄影 / 插画 / 设计与 3D / 艺术风格），生视频 13 个（镜头运动 / 片种），每个技能是一套结构化模板
  （主体 + 场景 + 风格 + 光线 + 镜头 + 氛围），「使用模板」会把 `{subject}` 换成你已写的短提示词或留出占位并选中，
  「叠加风格」把风格短句追加到现有提示词；下方的光线 / 镜头 / 氛围 / 质感（视频：运动 / 影调）修饰词可单个开关。
  内容按 OpenAI 图像提示指南、Midjourney / Stable Diffusion 社区风格参考与 GitHub awesome-prompts 类仓库的通行写法
  重新撰写，中英文各一套；要增删技能只改这一个数据文件。

## 第二轮：登录弹窗 · 多配色 · 控制台质感（`ui-palettes-auth-popup`）

### 登录 / 注册改成真正的弹窗（`src/router/authOverlay.ts`、`App.vue`、`AuthLayout.vue`）
- 在任何公开页面（首页、模型广场、协议页、密钥查询……）点「登录 / 注册」，或点了需要登录的入口被守卫拦下，
  对话框都**直接弹在当前页面上方**：当前页面保持渲染、不跳走、不重载、滚动位置不变。
  弹窗内 登录 ⇄ 注册 ⇄ 找回密码 ⇄ 邮箱验证 只切换表单，遮罩不闪。
- 关闭方式：右上角 ×、Esc、点击遮罩空白处（从表单拖出去的文字选择不算），关闭时有收起动画，然后回到原页面。
- 直接打开 `/login`（书签、刷新、从控制台退出登录）时没有可以垫在下面的页面，仍显示原来的星空全屏版。
- 路由、守卫、登录后跳转逻辑都没改；URL 仍是 `/login`、`/register`。
- 公开页面在弹窗下读取路由参数改用 `useDisplayedRoute()`（模型广场、协议页已改），避免读到 `/login` 的参数。

### 多配色（`src/styles/palettes.css`、`tailwind.config.js`、`src/composables/useAppearance.ts`）
- 7 套配色：黑金（默认，见第三轮）/ 余烬（原品牌色）/ 极光 / 星云 / 量子 / 矩阵 / 绯红。顶栏右侧的小圆球打开「外观」面板，
  可选配色、深色 / 浅色 / 跟随系统、动效 完整 / 减弱；选择存在 localStorage（`palette`、`theme`、`motion`）。
- `primary` / `accent` / `gray` / `dark` / `paper` / `ink` / `signal` 全部改为 CSS 变量，切换 `<html data-palette>`
  整站即时换色（含 `bg-primary-500/10` 这类透明度写法）。非默认配色按余烬的明度阶梯在 OKLCH 里生成，
  各配色的按钮色 600 对白字都 ≥ 4.6:1。状态色（红绿黄）不随配色变化。
- 图表（模型/分组/端点分布、Token 趋势、管理端用户趋势、仪表盘环形图）跟随当前配色与深浅色。
- 切换时整页交叉淡入（支持 View Transitions 的浏览器），否则颜色统一过渡。

### 控制台质感与动效（`src/style.css`、`src/composables/useInterfaceMotion.ts`）
- 登录后的控制台背景保持纯色，不加粒子、几何体、网格等装饰；层次放在面板上：细边框、分层柔阴影、
  深色下面板顶部的微弱高光、玻璃顶栏和侧边栏。
- 交互：按钮悬停微抬起、按下弹性回弹、聚焦环、禁用、`btn-loading` 忙碌态；输入框悬停 / 聚焦光晕 / 出错 / 只读 / 禁用；
  开关、标签页、下拉、弹窗、Toast 改为弹性曲线；侧边栏当前项的信号条带光晕。
- 所有控制台页面自动获得：面板滚动渐入（错落出现，含数据加载后才出现的面板）、`.stat-value` 数字从 0 滚动到真实值、
  鼠标在小面板上移动时的跟随光斑。不改布局、不留 transform，不会影响面板里未 teleport 的弹窗。
- 「动效：减弱」或系统开启减少动态效果时，以上全部关闭。

### AI 对话（`/chat`：`src/views/user/ChatView.vue`、`src/api/chat.ts`、`src/composables/useChat.ts`）
- 侧边栏「工作区」新增「AI 对话」。首次进入按三步走：选择密钥（卡片显示分组与平台）→ 选择该分组可用的模型 → 开始对话。
- 模型列表按密钥所在分组得出：优先用「可用渠道」接口里该分组的对话模型（带单价，图像 / 视频计费模式的模型排除）；
  没有公开渠道时请求网关的 `GET /v1/models`；都没有时给该平台的常用模型并注明，也可直接输入模型名。

- **生图「打开」按钮**：网关返回的图片是 `data:` 地址，浏览器禁止在新标签页直接打开 `data:` 地址（Chrome / Edge 点了没反应或空白页）。现在生成完成的图片转成本页的 `blob:` 地址（`src/utils/objectUrl.ts`），「打开」「下载」都正常，内存也更省；图片移出胶片条、清空或离开页面时释放。站点默认 CSP 的 `img-src` 已包含 `blob:`，不需要改后端。
- **首页太阳光效**（`src/components/home/SolarSystem.vue`）：
  - 日冕外壳的亮度原来按「1 − 朝向」计算，最亮处落在外壳边缘，在太阳外两倍半径处出现一圈脱离太阳的光环（拉近到地球视角时最明显）。改为按视线离太阳中心的距离计算：贴着太阳边缘最亮，向外衰减到外壳边缘为零。
  - 帧率偏低的电脑会自动切到省电画质。原来省电画质直接渲染到画布，跳过了色调映射和 sRGB 输出，切换的一瞬间太阳变成一团平涂的橙色、光晕消失、行星发暗。现在省电画质仍走后处理，只关掉泛光，画面和完整画质基本一致。
